Este proyecto es una aplicación de consola desarrollada en C#
diseñada para administrar y automatizar el flujo operativo de una empresa de mensajería y logística
Implementa los principios fundamentales de la Programación Orientada a Objetos(POO) como herencia,
polimorfismo, encapsulamiento y abstracción para el control de clientes, vehículos, repartidores, paquetes y entregas.
Caracteristicas:
Gestión de Usuarios y Personal: Registro y control de clientes (remitentes/destinatarios) y repartidores con estados operativos.
Motor de Verificación de Entregas: Módulo central (VerificarEntrega.cs) que valida compatibilidad de peso,
disponibilidad de recursos en tiempo real y asignación de tarifas integradas
